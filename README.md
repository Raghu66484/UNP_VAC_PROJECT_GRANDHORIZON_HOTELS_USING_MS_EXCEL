# UNP_VAC_PROJECT_GRANDHORIZON_HOTELS_USING_MS_EXCEL


I am Raghuveer, a B.Com (Honours) student who successfully completed a Business Analytics project in collaboration with UNP Education. The project involved working with hospitality revenue data using Microsoft Excel. My contributions included data preprocessing, removing duplicates, handling missing values, outlier detection, dummy variable encoding, dashboard development, and data visualization. I also performed hypothesis testing, ANOVA, T-tests, correlation analysis, and simple and multiple linear regression to identify business trends and generate meaningful insights for data-driven decision-making.
